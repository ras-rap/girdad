
# GIrDAd

![Magazine page](/images/zine.png)


A modern USB-C dongle/device for IrDA SIR.

![Render of GIrDAd](/images/render.png)
## What is this?
This is a IrDA VCOM device/dongle port thing, it has USB-C on one end, and an IrDA transceiver on the other.

## Why did you make this
I bought a Cipherlab 8001 Mobile Computer at a thrift store, and I want to program it, but I dont want to buy one of the data cradles for it, as they are way too rare and expensive for some pogo pins and an IrDA transceiver, so now we have this, which can be used for much more than the thing I built it for.

![8001 Mobile Computer](/images/Scanner.png)

## How do I use it
Well that depends on what you're using it for, but you plug it into your computer, and open up whatever program wants an IrDA SIR port, and use it like you would a device from the late 90's early 2000's

## Specs

- 115.2 kbp/s max transfer rate
- 870-910 nm wavelength
- 1m max usage distance
- 115200 max baud
